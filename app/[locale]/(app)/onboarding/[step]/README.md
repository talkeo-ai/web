# onboarding/[step]

The step lives in the URL, not in client state. That is what makes the browser's back button
work and lets a half-finished onboarding be resumed on day two.

The client does not own the sequence. The onboarding is the focus selector running in MEASURE
mode: it branches — the zero gate reroutes in two or three items and is refutable in both
directions — so this route renders whatever step the Core hands it and posts an answer back.

Which steps exist and what each one asks is defined outside this repository.
